Windows 10/11, 64-bit. No separate .NET installation is needed.

Getting started
---------------
1. Extract the entire AuctionPurchase folder from the ZIP.
2. Place it in a folder where you can save files, such as Documents.
3. Open AuctionPurchase.exe.

The app creates its database on first launch and includes the built-in
garden, broker and grade lists. This distribution has no sales history.

Setup
-----
Open Settings to enter the company profile and choose your preferences.
Open Companies to group gardens by owner. New sale accounts default to
the selected garden; you can choose another garden from the same company.

Files
-----
Data     - database and settings
Backups  - backups created in Settings
Exports  - exported PDF, Excel and Word reports

Keep the whole folder together when moving the app to another location.
Close the app before moving it or replacing the executable.
To move existing records to this copy, use Backup & Restore in Settings.

Excel uploads
-------------
Use New Sale > Template for the current workbook format. Account is an
optional last column. A blank Account uses the selected Garden.
